# jdfilter

Splitting-up schemes for nonlinear filtering of jump-diffusions with diffusive and Cox (point-process) observations. The repository contains the solvers, convergence experiments and particle-filter comparisons.

**Authors:** Ana Poklukar, Darja Rupnik Poklukar

The experiments of the paper *First-order time splitting for the Zakai equation with a jump-diffusion signal and Gaussian and Cox observations* (submitted to Advances in Computational Mathematics) and how to reproduce them are described in [`experiments/paper/README.md`](experiments/paper/README.md).
